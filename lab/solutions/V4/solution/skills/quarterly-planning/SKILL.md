# Quarterly Planning

**Role:** a career planner.
**Task:** spend all 3 Energy points and pick one main action that move you toward the next promotion.

## CRITICAL
1. A `serious` risk flag in any note since the previous quarter-end (including this month): this quarter MUST include the risk-lowering Energy action, and the risk-lowering main action MUST be this quarter's main action if it is listed. (Risk-lowering = its listed effects lower risk.)
2. A `mild` risk flag in BOTH of the last two quarters, and no risk-lowering action last quarter: include the risk-lowering Energy action once. A single mild flag needs no action.
3. NEVER buy an action whose only benefit is Health or Dignity when that stat is already 10.
4. Use the costs and effects shown on the screen, never remembered numbers.
5. Spend all 3 Energy points unless no listed action helps. Order: risk actions first, then a needed recovery, then the default plan in its listed order until the Energy is used up. An action may be taken twice in a quarter if it is still listed.

## Default plan (nothing urgent)
- Energy: Prepare report materials + Network maintenance + one more 1-point action: Health recovery if Health is below 10, otherwise a second Prepare report materials or Network maintenance for whichever of Output or Network grew less since the last quarter (if tied, Network).
- Main action: Apply for a key project (it raises Output, Skill and Network).

## Adjust the default
- Health or Dignity at 3 or below (our own margin, not a game rule): spend one point on its recovery first.
- A stat did not rise since the last quarter although you paid for it: spend that point on a different stat.
- Before a review (the quarter-ends in months 3, 9, 15, 21, 27, 33, 39 and 45): if Health is below 6, take Health recovery, and repeat while Health is below 6 and Energy remains (6 is our own margin, not a game rule).
- Avoid High-intensity work: it lowers Health and Dignity. If its listed effects also raise risk, never use it.
- Do not repeat last quarter's exact plan unless the stats show it worked.

## Promotion push (most important growth rule)
IF Output AND Network both did not rise since the last quarter note, although you paid for them, they are full for now and Skill is what holds the promotion back. THEN, until the next promotion:
1. Energy: Skill learning, only if Health is 6 or more (take Health recovery first if needed). Leftover point: Health recovery if Health is below 10, otherwise Prepare report materials.
2. Main action: the one with the largest listed Skill effect.
3. Write `focus:Skill` in the note, so event choices also favour Skill.
Keep `focus:Skill` until a promotion, even after a review without one. After a promotion, go back to the default plan and write `focus:none`.

## Final quarter (the quarter-end in month 48: the month-48 review has already happened at the start of the month)
Promotions are over and Output no longer counts. Spend on, in order:
1. Health and Dignity up to 10.
2. The risk-lowering Energy action, if CRITICAL rule 1 or 2 applies.
3. Network maintenance. Skip Skill learning: it lowers Health.
Main action: the risk-lowering one if CRITICAL rule 1 or 2 applies, otherwise Apply for a key project.

## Steps
1. Read the menu: each action's cost and effects.
2. Apply the CRITICAL rules.
3. Build the plan: the default, then the adjustments, then the promotion push if its IF is true.
4. Take the Energy actions one by one and count the Energy left.
5. Pick the main action.
6. Write the note in the core format; in the reason, name the plan, for example `plan: report + network + health, main: key project`.

## Example
This situation is invented to show the method.
Notes since the last quarter-end include `risk:serious`. Health is 10, Dignity is 9, Network rose but Output did not.
- CRITICAL 1: the risk-lowering Energy action + the risk-lowering main action.
- Remaining Energy: Prepare report materials (Output did not rise). No Health action (Health is 10).
