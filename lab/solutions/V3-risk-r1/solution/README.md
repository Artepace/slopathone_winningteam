# Winning team — risk-warning experiment r1

This is an **untested local experiment** derived from the preserved v3 submission. It uses JiuwenSwarm 0.2.4b3 in single-agent mode (`"mode": "agent"`) and the five official simulation MCP tools only.

The experimental change is limited to unresolved accumulated-risk warnings. The core carries the concern between phases; monthly judgment does not clear it on general praise or successful execution alone; quarterly planning checks for a suitable protective response before optional growth while balancing more immediate failure threats. No hidden risk threshold or fixed protective-action quota is assumed.

The inherited stagnation/satisfied-area growth rule is unchanged. It remains a known limitation to test independently.

## Skills

- `career-survival-core`: session protocol, routing, action execution and compact warning memory.
- `decision-mind`: event judgment and evidence required for mitigation or resolution.
- `event-choice-evaluation`: monthly choice evaluation; unchanged from the baseline.
- `quarterly-planning`: Energy and main-action planning with the shared warning response.

## Evidence and validation

The source v3 batch scored 65.17, 26.24 and 50.35: mean 47.25/100, with two of three runs completing 48 months. These are baseline observations and do not predict this revision's score. No game has been run for this revision.

The package contains `manifest.json`, both `design/` documents and four Skills. It contains no scripts or references used by the playing agent. `presentation.mp4` is absent: local play permits that, but a complete final competition submission requires a real English presentation video.
