# Quarterly Planning

**Role:** a career planner.
**Task:** spend all 3 Energy points and pick one main action that move you toward the next promotion.

## CRITICAL
1. A `serious` risk flag in any note since the last quarter-end: this quarter MUST include the risk-lowering Energy action and, if it is listed, the risk-lowering main action. (Risk-lowering = its listed effects lower risk.)
2. A `mild` risk flag in BOTH of the last two quarters, and no risk-lowering action last quarter: include the risk-lowering Energy action once. A single mild flag needs no action.
3. NEVER buy an action whose only benefit is Health or Dignity when that stat is already 10.
4. Use the costs and effects shown on the screen, never remembered numbers.
5. Spend all 3 Energy points unless no listed action helps. Order: risk actions first, then a needed recovery, then the default plan until the Energy is used up.

## Default plan (nothing urgent)
- Energy: Prepare report materials + Network maintenance + one more 1-point action: Health recovery if Health is below 10, otherwise a second Prepare report materials or Network maintenance for whichever of Output or Network grew less since the last quarter.
- Main action: Apply for a key project (it raises Output, Skill and Network).

## Adjust the default
- Health or Dignity at 3 or below (our own margin, not a game rule): spend one point on its recovery first.
- A stat did not rise since the last quarter although you paid for it: spend that point on a different stat.
- Skill grew least for two quarters: main action Apply for rotation or Build a mentorship instead of the key project.
- Avoid High-intensity work: it lowers Health and Dignity. If its listed effects also raise risk, never use it.
- Do not repeat last quarter's exact plan unless the stats show it worked.

## Final quarter (the quarter-end in month 48: the last review has already happened)
Promotions are over and Output no longer counts. Spend on, in order:
1. Health and Dignity up to 10.
2. The risk-lowering action, if any risk flag appeared in the last two quarters.
3. Skill, then Network.

## Steps
1. Read the menu: each action's cost and effects.
2. Apply the CRITICAL rules.
3. Build the plan: the default, then the adjustments.
4. Take the Energy actions one by one and count the Energy left.
5. Pick the main action.
6. Write the note in the core format; in the reason, name the plan, for example `plan: report + network + health, main: key project`.

## Example
This situation is invented to show the method.
Notes since the last quarter-end include `risk:serious`. Health is 10, Dignity is 9, Network rose but Output did not.
- CRITICAL 1: the risk-lowering Energy action + the risk-lowering main action.
- Remaining Energy: Prepare report materials (Output did not rise). No Health action (Health is 10).
